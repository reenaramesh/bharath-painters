# Bundled PDF fonts

Noto Sans Kannada, Telugu, Devanagari, and Tamil from the Google Fonts
repository are licensed under SIL Open Font License 1.1. Each font's license
is bundled beside it. PyMuPDF Story uses HarfBuzz shaping for HTML PDFs.

These files must be included in the Render backend artifact; no fonts are
downloaded during a PDF request.
