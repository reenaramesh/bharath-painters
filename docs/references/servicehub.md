# ServiceHub reference

Repository: https://github.com/aftabmujawar/ServiceHub
Reviewed: 2026-10-08

ServiceHub is a separate local-service marketplace application. Its README describes a React/Vite frontend, Spring Boot backend, and MySQL database. The repository page identifies an MIT license; check the actual license and retain required notices before reusing source code.

Use this repository as a reference when discussing or improving contractor discovery, provider profiles, location/service filters, booking flows, and customer/provider dashboards in Bharath Painters.

This reference does not install a Codex skill, plugin, dependency, Git remote, or application integration. No ServiceHub source code has been copied into this project.

Before adapting a feature, inspect its current source and map it to the existing Bharath Painters workflows. Preserve existing project changes, authentication, access permissions, API contracts, and business rules. Do not run ServiceHub setup scripts or connect its database to this application as part of reference-only work.
